# Independent verification run — 2026-10-30

These runs were made by the maintainer on the local, disposable labs only
(loopback), using the profiles and the dispatcher from this branch.

Environment: Docker Desktop on macOS arm64; official `php:<version>-apache`
images under `--platform linux/amd64` (except 8.5.11 aarch64), the lab
`php.ini`/`apache.conf` from `lab/rce/`, one prefork worker,
`display_errors=On`, `memory_limit=8M`, `post_max_size=512M`.

Command shape:

```sh
python3 tools/php2shell_auto.py \
  -u http://127.0.0.1:<port>/index.php \
  --container p2s-verify-<version> \
  --repo-dir <upstream-checkout> \
  --profile php-<version>-bookworm-<arch> --arch <arch> \
  -c 'id>/out/p1'
```
