# Independent verification run — 2026-10-30

These runs were made by the maintainer on local, disposable labs only
(loopback), using the profiles and the dispatcher from this branch. The
profiles therefore carry `contributor-reported, maintainer-confirmed` in their
`status`: the contributor supplied the calibration, the maintainer reproduced
it.

Environment: Docker Desktop on macOS arm64; official `php:<version>-apache`
images under `--platform linux/amd64` (except 8.5.11 aarch64), the lab
`php.ini`/`apache.conf` from `lab/rce/`, one prefork worker,
`display_errors=On`, `memory_limit=8M`, `post_max_size=512M`.

Docker Hub hit its unauthenticated pull limit during the review, so the later
images were pulled from the public `mirror.gcr.io/library/php` mirror by the
same amd64 manifest digests. That does not change the image contents.

Command shape:

```sh
python3 tools/php2shell_auto.py \
  -u http://127.0.0.1:<port>/index.php \
  --container p2s-verify-<version> \
  --repo-dir <upstream-checkout> \
  --profile php-<version>-bookworm-<arch> --arch <arch> \
  -c 'id>/out/p1'
```

Result: `PRE-AUTH RCE CONFIRMED` with `uid=33(www-data)`.
